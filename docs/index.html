An event-driven SpringBoard surface

A little more room for what matters.

Neo Island brings a compact, expandable activity surface to selected jailbroken iPhones. It reads live system signals and keeps the interface out of the way when there is nothing to show.

02 / Signals

Connected to real system state.

Updates are event-driven where iOS provides a signal. Timer ticks are limited to the active countdown; there is no background polling loop.

♫

Now-playing metadata, artwork and playback controls from the system player.

This is an independent jailbreak tweak, not an Apple system component. Notification previews, Clock app timers, Live Activities, incoming calls and Dynamic Island hardware integration are not implemented. Runtime testing on jailbroken devices is still required.
03 / Installation

Match the package to your bootstrap.

Rootful and rootless packages have different install paths. Confirm your jailbreak type and recovery method before installing a SpringBoard tweak.

01
Check prerequisites

Jailbroken iPhone, iOS 15+ target, a compatible MobileSubstrate/ElleKit bootstrap and PreferenceLoader. Compatibility has not been verified across devices.

02
Choose the right package

Install the Rootful `.deb` on a rootful jailbreak or the Rootless `.deb` on a rootless jailbreak. Do not mix them.

03
Install and respring

Use your package manager, review dependencies, then respring if requested. Keep your jailbreak's Safe Mode or recovery steps available.

04
Configure in Settings

Open Settings → Dynamic Island. Device-level Settings and SpringBoard stability testing is still outstanding.
